一.实时动能博弈
（1）MVRV的3种反应: 通过换手价格来进行实时博弈。

在日级别的K线基本上,价格上升,但是幅度越来越小,
MVRV不断下跌,说明老人平仓,新人接仓.并且价格没有大规模下跌,甚至略有上浮.
如果发生在牛市初期,这是一次健康的换手和价格基底重铸.
如果发生在牛市末期,理论上这应该是牛市双重顶的第二次顶部,老人最后一次的出清.

使用MVRV的关建原则是,自己在宏观的哪个趋势中,才能从趋势中通过MVRV指标提前收到正确的市场信息.

日K级别,价格上涨:
MVRV下跌,换手和筑底期,横盘时间久,选择趋势交易,后期右侧做多.
MVRV保持不变,隐蔽的派发.并且市场结构是双重顶的话,择机做空.
MVRV上涨,有人在拉盘,同时多头惜售,左侧多,但是注意盈利高,且风险高.泡沫重.

价涨 + MVRV降 = 车轻，油满。主力在洗盘，耐心等突破，大举买入。
价涨 + MVRV平 = 车重，油耗快。如果是第二个顶部,主力在出货，谨防假突破，准备做空。
价涨 + MVRV涨 = 车速极快，在此刻。情绪在加速，必须系好安全带（带止损），顺势冲浪但随时跳车

价格底部:
价平 + MVRV涨 = 车变轻了,散户最后的投降,恐慌抛售中,但是价格竟然不跌.说明有人在托盘.这是黎明的曙光.
价平 + MVRV跌 = 不存在,除非是远古巨鲸在这个位置卖出.
价平 + MVRV平 = 垃圾时间,没人买也没人卖.

价跌 + MVRV跌 = 车还是很重,高位持仓者不卖.
价急剧下跌 + MVRV平 = 车越来越轻,一次性全部卖完.俗称一根大阴线结束所有抛压,高位持仓者大量抛售,容易快速见底,后续容易V反.
价跌 + MVRV涨 = 不存在,因为一旦MVRV狂跌,价格只会跌的更快.现货狂跌,价格只会跌的更快,而不会跌的更慢.
当前局势：价格刚从底部上涨，但是出现了价格和MVRV出现了上涨背离，也就是大量换手。这是重新筑底阶段，需要等待后续的右侧多。，

只能给出一个信息就是，之前暴涨过，但是还没怎么跌过。或者是之前暴跌过，但还没有怎么涨过。

三、趋势，共识和约定好的经典，但是越明显的指标，反身性越强。导致越明显的利好信息，会导致利好提前用尽。
越明显利空的信息，会导致利空会提前用尽。

说到趋势，EMA均线是最常用的指标。但是要注意EMA均线采用纯价格，没有成交量，完全是心理作用，所以

1.ADX 是真实有用的趋势。 目前仍然在暴跌的阴霾中，如果此刻做多，那就是左侧多。左侧多无法赚趋势的钱，趋势更多的是利好出尽。只能赚极限超卖后，空头回补的钱。如果此刻做空，那就是赚利好出尽的钱。属于右侧空。
2.MACD 的金叉和死叉，常用来被当成利空出尽和利多出尽。峰顶和谷底，用来判断双重顶和双重底。
3.EMA ,一种幻觉，一种心理作用。要么踩在趋势线之上，要么落在趋势线之下。一种市场共识，需要额外关注。需要注意，趋势线无法反应市场真实面貌，必须结合成交量和OI。
EMA趋势线，虽然进场实际很难早，但是用来找平常时机则非常完美。因为亏本最大的源头不是多次小亏，而是逆势进场。
